# 🌐 무역 직무 MBTI 진단 테스트 (Trade MBTI)

> **"나의 업무 성향과 가장 잘 맞는 무역 직무는 무엇일까?"**  
> 20개 문항의 5점 척도 응답을 기반으로 업무 성향 4대 축을 분석하여 최적의 무역 직무(6개 직무)와 적합도를 도출하는 Streamlit 웹 애플리케이션 프로젝트입니다.

## 1. 프로젝트 개요

* **목적**: 무역·물류 취업준비생, 이직 희망자 및 실무자를 위한 직무 적합성 진단 및 실무 가이드 제공
* **방식**: 20개 문항에 대해 **5점 척도(1: 전혀 아니다 ~ 5: 매우 그렇다)** 응답
* **구현 플랫폼**: Python **Streamlit** 기반 반응형 웹 애플리케이션
* **주요 기능**:
  - 세션 기반 설문 진행 (단계별 폼 제공)
  - 4대 성향 축 정규화 점수 산출
  - 6개 무역 직무별 적합도(%) 랭킹 산출
  - 방사형(Radar) 성향 시각화 차트 및 직무 상세 카드 제공
  - 감성적인 파스텔 연보라톤(Soft Lavender) UI 테마 적용

## 2. UI/UX 디자인 및 테마 시스템 (Soft Lavender)

사용자 친화적이고 편안한 몰입감을 주기 위해 **파스텔톤 연보라(Lavender)** 계열의 테마를 기본 컬러 팔레트로 적용합니다.

### 2.1 컬러 팔레트 (Color Palette)

| 구분 | 색상명 | HEX 코드 | 용도 및 적용 대상 |
|---|---|:---:|---|
| **Primary** | Lavender Violet | `#8A79D6` | 주요 버튼, 프로그레스 바 활성 상태, 라디오 버튼 선택 강조 |
| **Primary Dark** | Deep Lavender | `#6E5BB8` | 버튼 호버(Hover), 1위 직무 카드 타이틀 및 주요 헤더 |
| **Secondary / Accent** | Muted Purple | `#B8A9E8` | 서브 뱃지, 태그, 보조 차트 라인 |
| **Background** | Pale Mist Lavender | `#F9F8FD` | 전체 웹페이지 기본 배경색 |
| **Surface / Card** | Pure White | `#FFFFFF` | 문항 박스, 결과 요약 카드, 섀도우 컨테이너 배경 |
| **Card Accent** | Soft Tint Lavender | `#F1EFFF` | 사이드바, 결과 팁 박스, 찰떡 궁합 안내 박스 배경 |
| **Text Primary** | Dark Slate Purple | `#2D283E` | 메인 본문 텍스트, 타이틀 (가독성 높은 짙은 퍼플 그레이) |
| **Text Muted** | Slate Gray | `#6E6A7C` | 보조 설명, 문항 번호 라벨, 부가 텍스트 |

---

### 2.2 Streamlit 테마 설정 파일 (`.streamlit/config.toml`)
Streamlit의 네이티브 테마 설정을 통해 전체 컴포넌트에 연보라색 테마를 기본 반영합니다.

```toml
[theme]
primaryColor = "#8A79D6"            # 메인 강조색 (라디오, 버튼, 슬라이더)
backgroundColor = "#F9F8FD"         # 웹페이지 전체 배경색 (연한 파스텔 라벤더)
secondaryBackgroundColor = "#F1EFFF" # 사이드바 및 인풋 박스 배경색
textColor = "#2D283E"                # 본문 텍스트 색상
font = "sans serif"
```

## 3. 진단 체계 및 핵심 지표 (4대 축)

응답자는 4가지 대립되는 성향 축에서 점수를 획득합니다. 각 축당 5개 문항(총 20문항)으로 구성됩니다.

| 지표 축 | 약칭 (양수/음수) | 측정 성향 정의 | 대표 특성 |
|---|:---:|---|---|
| **대인 지향 vs 데이터 지향** | **R** (+)<br>vs<br>**A** (-) | 사람 중심의 커뮤니케이션을 선호하는가,<br>데이터/서류/규정 중심의 분석을 선호하는가? | • **R (Relationship)**: 대화, 네고, 라포 형성<br>• **A (Analysis)**: 엑셀, 단가 분석, 서류 검증 |
| **도전 돌파 vs 안정 관리** | **D** (+)<br>vs<br>**S** (-) | 새로운 시장을 개척하고 리스크를 감수하는가,<br>원칙을 준수하고 리스크를 최소화하는가? | • **D (Drive)**: 수주 확대, 신시장 개척, 리스크 테이킹<br>• **S (Stability)**: 클레임 방지, 규정 준수, 오차 제로 |
| **유연 순발력 vs 치밀 원칙** | **F** (+)<br>vs<br>**P** (-) | 돌발 변수에 즉각 유연하게 대처하는가,<br>사전 계획과 매뉴얼에 따라 치밀하게 처리하는가? | • **F (Flexibility)**: 즉각 대안 마련, 멀티태스킹<br>• **P (Precision)**: 체크리스트, 오탈자 교정, 계약 준수 |
| **글로벌 현장 vs 오피스 시스템** | **G** (+)<br>vs<br>**O** (-) | 해외 출장, 전시회, 물류 현장을 선호하는가,<br>본사 시스템, ERP, 서류 관제를 선호하는가? | • **G (Global)**: 현장 체감, 대면 소통, 시차 극복<br>• **O (Office)**: 서면 기록, 내부 SCM, 시스템 고도화 |

## 4. 타깃 무역 직무 6선

| 직무명 | 영문 표기 | 직무 캐릭터 콘셉트 | 핵심 성향 조합 |
|---|---|---|:---:|
| **해외영업** | Overseas Sales | 불가능을 가능케 하는 글로벌 개척자 | `R` + `D` + `F` + `G` |
| **무역영업관리** | Trade Operation | 1원, 1초의 오차도 허용 않는 오피스 관제탑 | `A` + `S` + `P` + `O` |
| **포워딩 / 국제물류** | Forwarding & Logistics | 꼬인 운송 라인도 풀어내는 실시간 해결사 | `(R/A)` + `D` + `F` + `G/O` |
| **수출입 통관 / 관세** | Customs & Trade Compliance | 법률과 규정으로 회사를 지키는 무역 수호자 | `A` + `S` + `P` + `O` |
| **글로벌 소싱 / 구매** | Global Sourcing & Procurement | 최적의 단가와 공급망을 발굴하는 네고 헌터 | `A` + `D` + `P` + `G` |
| **크로스보더 e-커머스 / 해외마케팅** | Cross-Border E-Commerce | 트렌드를 읽고 글로벌 장바구니를 채우는 전략가 | `R` + `D` + `F` + `O` |

## 5. 20개 설문 문항 (5점 척도)

> **응답 척도:**  
> `1: 전혀 그렇지 않다` | `2: 대체로 그렇지 않다` | `3: 보통이다` | `4: 대체로 그렇다` | `5: 매우 그렇다`

### [Part 1] R vs A (관계 지향 vs 분석 지향)
* **Q01.** 해외 바이어나 파트너와 직접 대화하고 관계를 맺는 일에서 큰 에너지를 얻는다.
* **Q02.** 무역 박람회에서 처음 보는 참관객에게 먼저 다가가 제품을 소개하는 것이 즐겁다.
* **Q03.** 상대를 설득할 때 수치 데이터보다 인간적인 유대감과 스토리텔링이 더 강력하다고 믿는다.
* **Q04.** 하루 종일 사람과의 소통 없이 서류나 엑셀 작업만 하면 쉽게 피로해진다.
* **Q05.** 파트너십에서 계약서의 세부 문구 검토보다 상호 신뢰 형성을 위한 미팅이 더 중요하다.

### [Part 2] D vs S (도전 돌파 vs 안정 관리)
* **Q06.** 안정된 기존 거래선을 유지하는 것보다 미개척 신흥 시장을 개척하는 것이 더 매력적이다.
* **Q07.** 조건이 까다롭고 납기가 촉박하더라도 매출 규모가 크다면 일단 수주를 추진하고 본다.
* **Q08.** 리스크를 감수하더라도 경쟁사를 제치고 대형 거래를 성사시킬 때 가장 보람을 느낀다.
* **Q09.** 단가를 크게 낮출 수 있다면 약간의 품질·납기 리스크는 감수하고 시도해 볼 가치가 있다.
* **Q10.** 안전한 무사고 관리보다 다소 마찰이 있더라도 공격적인 거래 성사를 선호한다.

### [Part 3] F vs P (유연 순발력 vs 치밀 원칙)
* **Q11.** 선적 지연이나 포트 혼잡 등 돌발 상황이 터졌을 때 즉각적인 순발력으로 대안을 찾아내는 편이다.
* **Q12.** 정해진 타임라인과 체크리스트에 얽매이기보다 상황 변화에 따라 유연하게 일정을 바꾼다.
* **Q13.** 서류의 사소한 오탈자나 디테일 검증보다는 전체 거래의 흐름을 신속히 빼는 것이 더 중요하다.
* **Q14.** 바이어의 갑작스러운 스펙 변경 요구에도 매뉴얼에 얽매이지 않고 임기응변으로 조율해 낸다.
* **Q15.** 공식적인 가이드라인이 모호하더라도 내 직관과 현장 판단을 믿고 빠르게 결정을 내린다.

### [Part 4] G vs O (글로벌 현장 vs 오피스 시스템)
* **Q16.** 잦은 해외 출장이나 시차 적응의 피로가 있어도 현지 시장을 직접 누비는 출장을 선호한다.
* **Q17.** 완벽한 서면 기록보다 다소 거칠더라도 통화나 메신저로 실시간 부딪히며 소통하는 게 편하다.
* **Q18.** 본사 SCM 시스템 고도화보다 해외 법인 주재원이나 현지 지사 파견 근무를 지망한다.
* **Q19.** 깔끔하게 정돈된 오피스 데스크보다 물류 창고, 선적 포트, 전시회 같은 현장감이 더 활기차다.
* **Q20.** 환율 변동이나 규제 개정 데이터 분석보다 현지 소비자·바이어의 체감 반응 관찰에 먼저 눈이 간다.

## 6. 점수 계산 및 결과 도출 알고리즘

### 6.1 문항 점수 정규화
각 문항 응답(1~5점)은 기준값 3점을 기준으로 `-2 ~ +2`로 변환됩니다.
$$\text{Score} = \text{Response} - 3$$
* 5개 문항의 합산을 통해 각 축은 **최저 -10점 ~ 최고 +10점** 범위의 값을 가집니다.
* `양수(+)`: R(관계), D(도전), F(유연), G(글로벌) 성향
* `음수(-)`: A(분석), S(안정), P(원칙), O(오피스) 성향

### 6.2 직무별 기준 프로필 벡터 (4차원 공간: R-D-F-G)
| 직무 | R-A 축 | D-S 축 | F-P 축 | G-O 축 |
|---|:---:|:---:|:---:|:---:|
| **해외영업** | +8 | +7 | +6 | +9 |
| **무역영업관리** | -8 | -8 | -9 | -8 |
| **포워딩 / 국제물류** | +2 | +6 | +9 | +3 |
| **수출입 통관 / 관세** | -9 | -9 | -10 | -7 |
| **글로벌 소싱 / 구매** | -4 | +6 | -6 | +7 |
| **크로스보더 e-커머스** | +6 | +8 | +5 | -6 |

### 6.3 적합도(%) 계산 방식: 유클리드 거리 정규화
사용자 벡터 $U = (u_1, u_2, u_3, u_4)$와 직무 기준 벡터 $J = (j_1, j_2, j_3, j_4)$ 간의 거리를 계산합니다.
$$d(U, J) = \sqrt{\sum_{i=1}^{4} (u_i - j_i)^2}$$
이후 최대 가능 거리($d_{\max} \approx 40$)를 기준으로 0~100% 적합도를 산출합니다:
$$\text{Fit}(\%) = \max\left(0, \left(1 - \frac{d(U, J)}{d_{\max}}\right) \times 100\right)$$

## 7. 결과 화면 구성 요소

1. **대표 직무 타이틀 & 캐릭터 카드**:
   - 1순위 추천 직무 및 싱크로율(%) 표시 (예: *적합도 92% - '글로벌 네고의 신, 해외영업'*)
   - 연보라색 하이라이트 뱃지 및 핵심 업무/매력 포인트 안내
2. **4대 성향 방사형(Radar) 차트**:
   - 소프트 라벤더 필 컬러(`rgba(138, 121, 214, 0.3)`)를 적용한 Plotly 레이더 다이어그램
3. **6대 무역 직무 적합도 랭킹**:
   - 1위부터 6위까지의 직무별 적합도(%) 프로그레스 바 시각화
4. **직무 케미스트리 (궁합 매칭)**:
   - **찰떡 파트너**: 실무 협업 시 시너지가 가장 높은 직무 (예: 해외영업 ↔ 무역영업관리)
   - **주의 파트너**: 업무 접근 방식 차이로 소통 조율이 필요한 직무
5. **취업/실무 치트키**:
   - 추천 자격증 (국제무역사, 무역영어, 물류관리사, 원산지관리사, 보세사 등)
   - 필수 툴 및 실무 역량 키워드

## 9. 설치 및 실행 방법

```bash
# 1. 저장소 클론
git clone https://github.com/your-repo/trade-mbti.git
cd trade-mbti

# 2. 가상환경 생성 및 활성화
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 3. 필수 패키지 설치
pip install -r requirements.txt

# 4. Streamlit 실행
streamlit run app.py
```
